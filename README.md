# Tema 9. Analizador de gastos personales.
Programa desarrollado en Java para analizar gastos a partir de un archivo de texto. 

## Formato del archivo de entrada:
El archivo de gastos debe llamarse gastos.txty ubicarse en la raíz del proyecto. 
Cada línea representa un gasto, sin encabezados, con el formato:

categoría, monto.

## ¿Cómo ejecutarlo desde IntelliJ?
- Abre el proyecto.
- Asegúrate de tener una gastos.txten la raíz con tus datos.
- Abre Main.java y ejecútalo con el botón ▶️.

## Funciones:
- Calcula el total gastado.
- Agrupa gastos por categoría.
- Identifica la categoría con mayor gasto.
- Calcula el porcentaje de cada categoría.
